☁️ Sincronização entre Dispositivos
Acesse seus dados em qualquer celular, tablet ou computador em tempo real usando o Firebase gratuito.
Sync ativo
Sua sala de sync:
  1. 1
    Acesse console.firebase.google.com e crie um projeto gratuito
  2. 2
    Clique em "Adicionar app" → Web (</>) e copie o objeto firebaseConfig
  3. 3
    Vá em Firestore Database → Criar banco → Modo de teste
  4. 4
    Cole o JSON acima, escolha um código de sala e ative
  5. 5
    No celular, abra o app e use o mesmo código de sala para sincronizar ✅
